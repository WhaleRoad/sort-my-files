# sort_files

一个按扩展名自动整理文件夹的小脚本。下载文件夹堆成垃圾场的时候跑一下，
图片、文档、压缩包各回各家。

## 用法

```bash
# 只看不动，先把结果列出来给你过一眼
python sort_files.py

# 指定文件夹
python sort_files.py "D:\下载"

# 确认没问题，真开始搬
python sort_files.py "D:\下载" --go
```

不加 `--go` 就永远是试运行模式，不会动你一个文件。

## 说明

- 只用标准库，不用装任何东西
- 重名文件会自动加序号，不会覆盖
- 分类规则在 `RULES` 里，想加什么后缀自己往里塞就行
